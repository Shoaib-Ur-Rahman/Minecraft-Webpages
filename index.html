HOW IT WORKS

Files stay up to date

This page reads its download list from GitHub Releases. When you publish a release and attach files, they appear here automatically; you don’t have to add each download link by hand.

Schematic files such as .litematic and .schem are linked as individual downloads. They aren’t image previews; add PNG/JPG screenshots as release assets if you want visual previews to appear here.

For ZIP assets, the release title or filename should say what they are (for example “Resource Pack”, “Shaderpack”, “Modpack” or “Xaero Map”) so the site can put them in the right category.
