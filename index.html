PUBLISHING FILES

Where to upload

Keep the website code in this GitHub repository. For small files, you can also store them in the repo and link to their GitHub URLs. Avoid committing large archives or frequently updated game files: they make the repository harder to clone and maintain.

For downloadable releases, use GitHub Releases and attach versioned files to a release. If a file is too large for convenient GitHub hosting, use a cloud storage or download-hosting service that supports stable public links, and link to it from the site.

For every upload, include the Minecraft version, loader or required mod, file version, installation/restore steps, and any source or license information. Only share files you made or are allowed to redistribute. Xaero map data can contain explored-world information, so check it before making it public.
