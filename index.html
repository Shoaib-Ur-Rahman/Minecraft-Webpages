HOW IT WORKS

Where files go

Use this GitHub repo for the website. Keep the front-end and links here. This keeps the project easy to edit and publish.

Upload actual files to GitHub Releases. That is the best place for modpack zip files, schematics, resource packs, shaderpacks and map files because each asset can have its own version and download URL.

For non-zip content, upload the raw file directly. Items like .litematic and .schem work fine as release assets. For image previews, add a screenshot with the same file and link that preview in the page.

Cloud storage is useful for large files. If a file is too large, upload it somewhere like Google Drive or Dropbox and link to it from the page. Keep the GH repo for code and release listing.
