PUBLISH A FILE

Upload through a release

The website code and downloadable files are kept in separate repositories. Upload public Minecraft files as assets in a GitHub Release in the files repository. The website collection pages read those releases and show download buttons.

To publish files:

  1. Create a release in the files repository.
  2. Give it a clear category title/tag, such as Schematics, Resource Packs, Shaderpacks, Xaero Maps, or Modpacks.
  3. Attach the actual files. Individual .litematic and .schem files are fine; folders such as map data should be zipped first.
  4. Publish the release. Matching assets will appear on the corresponding collection page.

Password safety: this is static GitHub Pages hosting, so a password stored in its HTML/JavaScript would be public and is not a real access lock. Do not commit passwords or access tokens. Use GitHub’s signed-in release form to manage uploads; a private upload dashboard requires a backend.
