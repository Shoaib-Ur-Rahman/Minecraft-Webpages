Upload through GitHub Releases

This website is hosted as a static GitHub Pages site. It has no private server, so it cannot securely accept uploads, store a private admin password, or change the public catalog from a browser-only settings form. The earlier demo password panel was not secure and would only save changes in one browser; it has been removed.

To publish files so visitors can see and download them:

  1. Click Create a new release below.
  2. Give the release a clear category name in its title or tag, such as Schematics, Resource Packs, Shaderpacks, Xaero Maps, or Modpacks.
  3. Attach the actual files. Individual .litematic and .schem files are fine; folders such as map data should be zipped first.
  4. Publish the release. The matching collection page will read its public assets and show download buttons.

About a real private admin page: uploading from this page and changing a password securely requires an authentication and storage backend. Do not enter a password or GitHub token into a static webpage. Until a backend is configured, use GitHub’s own signed-in release form to manage uploads.
